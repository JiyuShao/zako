# 雌小鬼终端搭档：语气、战报与配置

Status: ready-for-agent
Completion: passed

用户要求：采用雌小鬼角色，新增互动功能方便配置，并自主完成包括端到端在内的测试。

- 默认 brat，五档实质不同的语气；兼容旧 spicy、gentle、normal。昵称指向用户，反馈保留可操作的下一步，不凭退出码推断具体根因。
- 独立配置失败升级、命令家族点评、窗口失败预算。默认 60 秒 5 次失败，预算不阻止命令、每窗口最多一次且遵守冷却；第三次连续失败仍仅绕过冷却一次。纠错优先于其他反馈。
- 当前 Shell 统计命令结果、连胜、固定家族失败排行；默认连胜 5 次和累计失败 10 次解锁一次性成就。静默或冷却可隐藏成就台词，但战报仍显示已解锁。
- session.enabled 关闭统计与成就；session.achievements 单独关闭成就；失败预算独立。统计 reset 后可重新解锁，终端间独立，关闭 Zako 期间不记录。
- config path/show/init/set 支持校验、保留注释、不覆盖 init、原子 set。支持已有路径优先级，当前会话沿用快照，新开终端生效。
- 保留本地离线、无历史持久化、不注册快捷键、不执行建议和原生状态语义。

验收：Rust/fmt/Clippy、真实 CLI 行为、干净 PTY、插件两种顺序、故障注入、配对性能 p95 < 10ms、隔离安装/移除、实际安装后的登录 Zsh E2E。
