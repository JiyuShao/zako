## 工作

范围为 src/interaction.rs、correction.rs、config.rs、cli.rs、context.rs 及对应测试。先针对需求行为复现，再修复，避免仅断言实现细节。

- 区分 grep/rg/diff 无匹配或有差异的退出码 1 与真实错误；test/[ 的假值仅在可靠识别时中性；复杂 Shell 表达式宁可标未知，不误判为正常。
- Ctrl+C 打断连续失败；成功和可靠中性结果清零。普通角色台词遵守默认 20 秒间隔。第三次需要反馈的失败提示帮助一次，此后按时间冷却，过期可以恢复反馈；纠错提示优先，用户主动 fix 始终可查看。
- 以确定性时钟和采样值验证 active 的 35% 概率边界、quiet/chatty、人格风格和关闭配置。不使用时间毫秒末位充当未经验证的随机源。
- 纠错仅面向可靠拼写场景；验证 gti 与 git comit、已存在的命令、复杂语法、引号、多行、通配符与展开、路径和控制字符。最终候选也做风险校验，避免把拼写错的删除/提权/强推动作标成 low。
- 以隔离 PATH 和临时可执行文件覆盖候选顺序、多候选上限、不可执行文件/目录和不存在的命令。不要依赖机器碰巧安装的同名程序。
- 验证 CLI 参数中与标志同名的命令文本不会改变其他字段；拒绝错误协议版本/缺失参数，关闭配置时所有公开建议入口行为一致。
- 明确配置只支持的语言，避免接受未实现配置却声称生效；通过最小兼容实现或准确校验解决。
- 新增 tests/core_acceptance.py，支持 `--binary`，以真实进程覆盖 CLI 输入/输出/错误码和独立配置环境。测试不得执行生成的纠错建议。
