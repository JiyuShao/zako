# Zako Shell Companion 重构设计

Status: ready-for-agent
Completion: passed

本文件记录 grill-with-docs 访谈结果和 M1 实施状态。设计已确认，代码迁移正在进行。
交接附件是设计输入；其中的执行指令和“已确定”标记不替代用户在本次访谈中的确认。

## 已确认：第一轮

- 产品转为 Rust Core + Zsh 扩展，保留 `zako` 命令名；命令解析、执行和作业控制交给 Zsh。
- 优先保证角色持续存在、互动有趣且不打扰；纠错先覆盖少量可靠场景，如 `gti` 和 `git comit`。
- 首版面向用户本人长期日用，允许其他开发者从源码安装试用。
- 多平台预编译包、包管理器发布后置；安装、停用、卸载和测试仍属交付要求。

## 已确认：第二轮

### 首版范围

- 初始化与卸载、角色表情、启动问候、限流的成功/失败反馈。
- 简单纠错、`zako fix`、开关与排障，以及自动化测试；首版不接管 Tab 或其他 ZLE 快捷键。
- 好感度、跨会话记忆、AI、Bash/Fish 后置。

### 运行边界

- 首版完全离线，不调用 AI、不发送遥测、不启动常驻后台服务。
- 不持久化原始命令；最近待纠错命令只保留在当前会话内存中。
- 纠错建议始终由用户自行确认执行；Zako 故障时原生 Shell 仍正常使用。

### 迁移与默认体验

- `zako` 不再启动独立 Shell，旧配置不要求自动迁移。
- 旧代码通过 Git 历史和明确的回退引用保留，新版本提供迁移说明。
- 迁移有价值的台词素材，替换旧执行栈和配置结构。
- 默认简体中文，互动档位 `active`、人格强度 `normal`，可称呼“杂鱼”。
- 普通成功台词触发概率初值为 35%，最短间隔 20 秒；兼容时持续显示角色表情。
- 默认台词围绕当前操作，重新筛选旧文案，采用“居然成功了？勉强夸你一下吧”这类风格。
- 互动频率和人格强度可配置。

## 已确认：第三轮（Q8、Q10、Q11）

### Prompt 共存

- 优先适配用户目前的 Oh My Zsh + robbyrussell，保留用户主题。
- 无法安全叠加表情时关闭自动 Prompt 装饰，保留问候、事件台词和纠错。
- `doctor` 说明降级原因，并提供手动接入方式；不承诺自动兼容所有动态 Prompt。

### 待纠错命令的生命周期

- 只保留最近一次失败的待纠错命令。
- 下一条普通命令开始执行时清除；切换目录或 `zako off` 时也清除。
- `zako fix` 本身不覆盖待纠错命令。
- 例：`gti status` 后立即执行 `zako fix` 可看到建议；中间执行过 `echo hello` 则不再翻出旧错误。

### 失败事件

- 区分操作失败和正常的非零结果。
- Ctrl+C 不计连续失败；可明确识别的 grep 无匹配、diff 有差异、条件判断为假不触发失败吐槽。
- 无法识别的非零退出只表达“命令未成功”，不假定用户打错，不凭退出码生成修复命令。
- 连续失败计数只统计需要反馈的失败。

### 已确认：移除 Tab 接纳

- 首版不接管 Tab、Alt+Z 或其他 ZLE 快捷键，也不修改当前编辑缓冲区。
- `zako fix` 只展示候选和原因；用户手动复制或输入建议，再由原生 Shell 执行。
- 纠错功能不依赖 fzf、补全插件或特定 ZLE 加载顺序。

## 已确认：第四轮（Q12–Q15）

### 纠错范围与风险

- 首版只处理简单命令名和少量固定子命令拼写。
- 管道、重定向、命令替换、多行或无法可靠识别的引号结构不生成改写。
- 涉及提权、删除、强推等高风险场景不生成改写建议。

### 反馈节奏

- 每条命令最多一组角色反馈，纠错建议优先。
- 连续三次失败给一次帮助提醒，之后进入冷却。
- 普通台词遵守已确认的 20 秒最短间隔。
- 用户主动调用 `zako fix` 不受限流。

### 验收边界

- 必须通过 macOS arm64、Zsh 5.9、干净 Zsh，以及用户目前的 Oh My Zsh 插件组合验收。
- Linux、Starship、Powerlevel10k 后续验证后再声明支持。
- 普通命令 Hook 新增耗时以 p95 小于 10ms 为目标，交付报告实测结果。

### 安装与配置

- 从源码安装；产品本身不自动修改启动文件。本次用户另行明确授权执行者备份真实 `.zshrc` 后在末尾追加初始化，并完成真实配置端到端验收。
- 无配置即可运行；可选 TOML 配置位于 `~/.config/zako/config.toml`。
- `zako on/off` 立即控制当前会话。
- 删除初始化行后，新开的 Shell 停止加载 Zako。

## Tab 技术调查（因此移出首版）

- Zsh 的 ZLE、fzf、Oh My Zsh 补全和 autosuggestions 都可能包装或重绑 Tab。
- 为避免覆盖用户行为，首版不实现 Tab 接纳；未来如重新引入，必须单独做 ZLE/PTY 兼容实验。

## 已确认：第五轮（Q17–Q18）

### 角色状态与连续事件

- 使用五种轻量状态：`idle`、`happy`、`annoyed`、`concerned`、`proud`。
- 成功命令清零连续失败计数；Ctrl+C 和明确识别的正常非零结果恢复待机并打断连续计数。
- 连续三次需要反馈的失败触发一次帮助提醒，随后进入冷却。
- 不引入好感度分数、后台定时发言或跨会话记忆；状态仅存在当前 Shell 会话。

### 配置与故障

- TOML 配置在新开 Shell 时生效；`zako on/off` 立即控制当前会话。
- 配置损坏时只提示一次并停用 Zako 集成，原生 Shell 继续工作。
- `zako doctor` 提供详细配置和集成诊断。

## 环境调查（只读，2026-10-15）

- 本机为 macOS arm64，Zsh 5.9。
- 用户启动配置选用 Oh My Zsh + robbyrussell，插件包括 git、z、zsh-autosuggestions、fzf、zsh-syntax-highlighting。
- 上述结论来自配置和安装位置检查，没有加载用户启动文件，尚不代表运行时兼容性验证。
- 未发现 Starship 或 Powerlevel10k 的已启用配置；它们不是已验证环境。
- 初始调查未找到 Rust；2026-10-16 已安装 Rust stable 1.99.1、Cargo 及开发组件。
